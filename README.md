# Service Learning Project: Version Control with Git

1. git clone git@github.com:DJVolin/SLP.git
- clone will clone a repo into the current working directory
2. git checkout 
- Checkout can switch to and create new branches
3. git add
- Add will stage the specified files
4. git status
- status will show the working tree 
5. git commit
- git commit records the commit with a message 
6. git log
- Log shows the commit log, details all past commits made
7. git push
- push will push your commit to the current branch
8. git diff
- diff will show the changes between the commits and working tree
9. git merge
- merge will join two or more commit histories
10. git branch
- branch can list and manage local branches
11. git stash
- stash saves uncommitted changes and restores working directory to a clean state
12. git rebase
- rebase reapplies commits onto a new base commit
